# Kevin He

Personal site. Live at **[kevinyhe.com](https://kevinyhe.com)**.

Next.js 15, three.js, GSAP and Lenis.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushes to `master` deploy to production on Vercel (project `personal-site`). `.vercelignore` limits the upload to `app/`, `components/`, `public/` and the root config files.
